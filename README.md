# yujian-fonts

預見（yujianbooking.com）網頁使用的中文字型切片。每套字型切成數百個小檔，瀏覽器只下載畫面用到的字。

透過 jsDelivr 載入：

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tonys61311/yujian-fonts@1.0.0/xiaolai/result.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tonys61311/yujian-fonts@1.0.0/yujianpen/result.css">
```

| 資料夾 | CSS font-family | 來源 | 授權 |
|---|---|---|---|
| `xiaolai/` | `Xiaolai` | [小賴字體 Xiaolai](https://github.com/lxgw/kose-font) v3.126，© 2020-2024 LXGW、© 2014 Nozomi Seto | SIL OFL 1.1，見 `xiaolai/OFL.txt` |
| `yujianpen/` | `YujianPen` | 改作自 [辰宇落雁體 2.0 Thin](https://github.com/Chenyu-otf/chenyuluoyan_thin)，© 2022 王立宇、劉韋辰 | SIL OFL 1.1，見 `yujianpen/OFL.txt` |

辰宇落雁體的「辰宇落雁」「Chenyuluoyan」為保留字型名稱（Reserved Font Name）。本 repo 的切片屬於改作版本，因此改名為 YujianPen，不使用原名稱。

切片工具：[cn-font-split](https://github.com/KonghaYao/cn-font-split) 7.4。

本 repo 的字型檔依各自的 SIL Open Font License 1.1 授權，不得單獨販售。
